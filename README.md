# Tic-Tac-Toe in C

My first small programming project, built entirely in C.

This is a two-player command-line Tic-Tac-Toe game.

## Features

- 3×3 game board
- Two-player gameplay
- Input validation
- Prevents moves on occupied cells
- Win detection
- Draw detection
